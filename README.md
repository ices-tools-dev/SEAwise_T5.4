# SEAwise_T5.4
SEAwise WP 5, Task 5.4 - Effect of changes in habitat on productivity, species and habitats - SEAwise project


The first R code (Sole Irish Sea) , developed by Instittu Agro, allows to run the life cycle model used in WP54 about impact of nursery habitat size and quality at exploited fish population scale
This code was used for several case study on the western waters and the North Sea
It is here exemplified for the sole in the Irish Sea

The second (seawise 54 final script ILVO) is the one developed by ILVO to buid habitat suitability models based on beam trawl surveys for the common sole
