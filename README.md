Two R codes are  provided

This first R code (Sole_Irish_sea.Rmd), developed by institut Agro, allows for running the life cycle model used in WP54 about impact of nursery habitat size and quality at exploited fish population scale
This code was used for several case study on the western waters and the North Sea
It is here exemplified for the common sole in the Irish Sea

The second code (Seawise_t5-4_finalScript_Ilvo.R) was developed by Ilvo to develop habitat suitability models for the common sole from scientific beam trawl surveys, according to a panel of environmental descriptors
